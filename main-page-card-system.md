# Main page card system

Each domestic/commercial service card on `index.html` is an independent link + article block. Keep each card's image class, title, description, and destination together. When changing a card in future, modify only that card's image/content/link block and do not alter the shared grid/card CSS or other cards.

The Nursery card must remain an independent clickable card linking to the Nursery section/page.

This file documents the intended future-proof structure; it does not alter the live page by itself.
